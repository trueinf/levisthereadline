# Static assets (served at the site root by Vite)

Files here are served from `/`. For example `public/campaign-hero.webp` is available at `/campaign-hero.webp`.

## campaign-hero.webp

The "Behind Every Original" campaign uses `/campaign-hero.webp` in two places:

- the campaign card on Home / Campaigns, and
- the Overview hero inside the campaign workspace.

**Save your campaign image here as `campaign-hero.webp`** (this exact name). Until
the file exists, both placeholders fall back to the original gradient.

Commit the image so it also deploys to Netlify.
